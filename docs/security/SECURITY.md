# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### How to Report

Send an email to i.s.semernyakov@yandex.ru with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if known)

**Please do not:**

- Publicly disclose the vulnerability before it's fixed
- Use the vulnerability to harm others
- Exploit the vulnerability for any purpose

### What to Expect

- You will receive an acknowledgment within 48 hours
- We will assess the severity and impact
- We will work on a fix and coordinate disclosure
- We will credit you for the discovery (if desired)

### Security Best Practices

When contributing to this project, follow these security guidelines:

- Never commit sensitive data (API keys, passwords, tokens)
- Validate all user inputs
- Keep dependencies updated
- Use secure coding practices
- Review code for common vulnerabilities (XSS, SQL injection, etc.)

## Dependency Security

We regularly update dependencies to address security vulnerabilities. If you discover a security issue in a dependency, please report it following the same process.
