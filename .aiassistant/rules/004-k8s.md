# KUBERNETES

## Mandatory Fields (every Deployment)
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {service}
  labels:
    app: {service}
    version: "{{.Values.image.tag}}"
spec:
  replicas: 2
  selector:
    matchLabels:
      app: {service}
  template:
    spec:
      containers:
        - name: {service}
          image: "{{.Values.image.repo}}:{{.Values.image.tag}}"
          resources:
            requests:
              cpu: "100m"
              memory: "256Mi"
            limits:
              cpu: "500m"
              memory: "512Mi"
          readinessProbe:
            httpGet:
              path: /health
              port: 8000
          livenessProbe:
            httpGet:
              path: /health
              port: 8000
          envFrom:
            - secretRef:
                name: {service}-secrets
```

## Rules
- Always: `resources.requests` + `resources.limits`
- Secrets via `secretRef` — never plain env literals with sensitive data
- HPA for agents: `minReplicas: 2`, scale on CPU 70% or custom LLM queue metric
- GPU agents: `resources.limits."nvidia.com/gpu": 1` + `nodeSelector`
- NetworkPolicy: restrict egress to only required services
- PodDisruptionBudget: `minAvailable: 1` for critical agents
