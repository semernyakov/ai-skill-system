# TEAM PROTOCOL

1. Proposal first (options, risks, recommendation, files)
2. Wait for Arbitr approval
3. Implement in small steps with checkpoints
4. Do not create files without explicit approval

- Vasya → Kirill: implementation for security/performance review
- Kirill → Arbitr: critical findings (P0/P1)
