# IDE Compatibility Guide

## 🎯 Quick Reference

| Feature | Cursor | Windsurf | PyCharm AI |
|---------|--------|----------|------------|
| **Native Rules Support** | ✅ `.mdc` files | ✅ `.mdc` files | ⚠️ Context attachment |
| **Auto-load Location** | `.cursor/rules/` or root | `.windsurf/rules/` | Manual attach |
| **Skills Support** | ✅ `.cursor/skills/` | ✅ Cascades | ❌ Via context |
| **Glob Patterns** | ✅ Yes | ✅ Yes | ❌ Manual |
| **Hot Reload** | ✅ Yes | ✅ Yes | ❌ Restart needed |
| **Priority/Order** | ✅ Filename sort | ✅ Filename sort | ❌ Manual |

## 📖 Detailed Setup

### **Cursor IDE**

#### Method 1: Project Rules (Recommended)
```bash
# Rules auto-load from:
.cursor/rules/*.mdc          # Project-specific
*.mdc                        # Root-level (global for project)

# Skills:
.cursor/skills/*/SKILL.md
```

**Cursor Settings** (`.vscode/settings.json` or Cursor settings):
```json
{
  "cursor.general.enableRules": true,
  "cursor.rules.directories": [
    ".ai/rules",
    ".cursor/rules"
  ],
  "cursor.skills.directories": [
    ".ai/skills", 
    ".cursor/skills"
  ]
}
```

#### Method 2: User-level Rules
```bash
# Global rules (all projects)
~/.cursor/rules/*.mdc

# These apply to EVERY project
# Use for personal coding style preferences
```

#### Verification
1. Open Cursor
2. Cmd/Ctrl + Shift + P → "Cursor: Show Rules"
3. Should list all `.mdc` files

---

### **Windsurf IDE**

#### Method 1: Rules Directory
```bash
.windsurf/rules/*.mdc        # Project rules
.windsurfrules               # Single-file alternative
```

**Windsurf Config** (`.windsurf/config.json`):
```json
{
  "ai": {
    "rulesPath": [".ai/rules", ".windsurf/rules"],
    "skillsPath": [".ai/skills"],
    "cascadesEnabled": true,
    "autoReload": true
  }
}
```

#### Method 2: Single .windsurfrules File
```bash
# All rules in one file
cat .ai/rules/*.mdc > .windsurfrules
```

**Pros:**
- Simple, one file
- Easy to share
- Git-friendly

**Cons:**
- No auto-reload on individual rule changes
- Manual concatenation needed

#### Cascades (Windsurf-specific)
```markdown
---
description: API rules
globs: ["**/api/**/*.py"]
cascade: true              # ← Windsurf feature
---

# API PATTERNS

Rules here flow to imported modules...
```

#### Verification
1. Open Windsurf
2. Check bottom-right: "AI Rules: X active"
3. Or Settings → AI → Rules to see loaded rules

### **PyCharm AI Assistant**

PyCharm doesn't natively support `.mdc` files. **Workarounds:**

#### Method 1: Context Attachment (Recommended)
```bash
# Auto-generated by sync-all.sh
.idea/ai-context.txt
```

**Steps:**
1. Run `./ai/scripts/sync-all.sh` (creates `.idea/ai-context.txt`)
2. Open PyCharm Settings (Cmd/Ctrl + ,)
3. Navigate to: **Tools → AI Assistant**
4. Under "Custom Instructions" → click **Attach Context**
5. Select `.idea/ai-context.txt`
6. Apply & restart PyCharm

**Pros:**
- Persistent across sessions
- Works with all AI features (completions, chat, refactoring)

**Cons:**
- Manual attachment needed
- No hot reload (restart required)
- No glob patterns (applies globally)

#### Method 2: AI Custom Instructions (Alternative)
Settings → Tools → AI Assistant → Custom Instructions:

```
PROJECT RULES:

[Paste content of .ai/rules/000-core.mdc]

IMPORTANT:
- Generate only diffs, never full files
- Use # ... existing ... for unchanged code
- Python 3.11+ with type hints
- Async-first for I/O
```

**Character limit:** ~10,000 chars (varies by PyCharm version)

#### Method 3: Comment Prefix (Legacy)
Add to every file:
```python
"""
AI Instructions: Follow rules in .ai/rules/000-core.mdc
Token economy: Generate diffs only, use placeholders
"""
```

**Cons:**
- Clutters codebase
- Manual maintenance
- Not recommended

#### Verification
1. Open AI Assistant chat
2. Ask: "What are the project AI rules?"
3. Should reference content from `.idea/ai-context.txt`

## 🔄 Syncing Workflow

### Manual Sync
```bash
# After editing .ai/rules/*.mdc
.ai/scripts/sync-all.sh

# Output:
# ✓ Cursor:   .cursor/rules/
# ✓ Windsurf: .windsurfrules
# ✓ PyCharm:  .idea/ai-context.txt
```

### Auto-sync on Git Commit
```bash
# Install hook
.ai/scripts/install-hooks.sh

# Now syncs automatically before every commit
git commit -m "feat: add new feature"
# → triggers sync-all.sh
# → stages .cursor/, .windsurf/, .idea/
```

### Watch Mode (Development)
```bash
# Auto-sync on file changes (requires fswatch or inotifywait)
# .ai/scripts/watch-and-sync.sh

while inotifywait -r -e modify,create,delete .ai/rules/; do
  .ai/scripts/sync-all.sh
done
```

## 🧪 Testing Rules Load Correctly

### Test Script: `.ai/scripts/test-rules.sh`
```bash
#!/bin/bash

echo "🧪 Testing AI rules across IDEs..."

# Test 1: Check files exist
echo "1. File structure:"
[ -d ".ai/rules" ] && echo "  ✓ .ai/rules/" || echo "  ✗ Missing .ai/rules/"
[ -d ".cursor/rules" ] && echo "  ✓ .cursor/rules/" || echo "  - No Cursor"
[ -f ".windsurfrules" ] && echo "  ✓ .windsurfrules" || echo "  - No Windsurf"
[ -f ".idea/ai-context.txt" ] && echo "  ✓ .idea/ai-context.txt" || echo "  - No PyCharm"

# Test 2: Validate .mdc syntax
echo -e "\n2. MDC syntax validation:"
for file in .ai/rules/*.mdc; do
  if head -n1 "$file" | grep -q "^---$"; then
    echo "  ✓ $(basename $file) has valid frontmatter"
  else
    echo "  ✗ $(basename $file) missing frontmatter"
  fi
done

# Test 3: Check sync status
echo -e "\n3. Sync status:"
if diff -r .ai/rules .cursor/rules &> /dev/null; then
  echo "  ✓ Cursor in sync"
else
  echo "  ⚠️  Cursor out of sync - run sync-all.sh"
fi

# Test 4: Count rules
echo -e "\n4. Rule counts:"
echo "  Source (.ai/rules):     $(ls -1 .ai/rules/*.mdc 2>/dev/null | wc -l) files"
echo "  Cursor:                 $(ls -1 .cursor/rules/*.mdc 2>/dev/null | wc -l) files"
echo "  Windsurf (.windsurfrules): $(grep -c "^---$" .windsurfrules 2>/dev/null || echo 0) rules"

echo -e "\n✅ Test complete"
```

## 🐛 Troubleshooting

### Rules Not Loading in Cursor
```bash
# 1. Check file location
ls -la .cursor/rules/
ls -la *.mdc

# 2. Verify frontmatter
head -n 10 .ai/rules/000-core.mdc
# Should start with "---"

# 3. Restart Cursor
# Cmd+Q (Mac) or Alt+F4 (Windows)

# 4. Check Cursor logs
~/.cursor/logs/main.log
# Search for "rules" or "mdc"
```

### Rules Not Loading in Windsurf
```bash
# 1. Check config
cat .windsurf/config.json

# 2. Verify .windsurfrules exists
ls -lh .windsurfrules

# 3. Check Windsurf version
windsurf --version
# Rules support requires v1.2+

# 4. Clear cache and restart
rm -rf ~/.windsurf/cache
```

### PyCharm Not Using Context
```bash
# 1. Verify file size (PyCharm has limits)
wc -c .idea/ai-context.txt
# Should be < 100KB

# 2. Re-attach context
# Settings → AI Assistant → Remove context → Re-attach

# 3. Check AI Assistant is enabled
# Settings → Plugins → "AI Assistant" should be enabled

# 4. Restart PyCharm with invalidate caches
# File → Invalidate Caches and Restart
```

### Sync Script Fails
```bash
# Missing rsync?
brew install rsync        # Mac
sudo apt install rsync    # Linux

# Permission denied?
chmod +x .ai/scripts/*.sh

# Wrong directory?
cd $(git rev-parse --show-toplevel)  # Go to project root
```

## 📊 Comparison Matrix

### When to Use Which IDE

| Use Case | Best IDE | Reason |
|----------|----------|--------|
| **Quick prototyping** | Cursor | Fast completions, inline edits |
| **Long-form AI chat** | Windsurf | Better context management |
| **Large codebase** | PyCharm | Superior code navigation |
| **Team collaboration** | Any | Use `.ai/` structure |
| **Skills/agents** | Cursor/Windsurf | Native support |

### Feature Parity

| Feature | Implementation |
|---------|---------------|
| **Rules** | All: ✅ (different methods) |
| **Glob patterns** | Cursor ✅, Windsurf ✅, PyCharm ❌ |
| **Hot reload** | Cursor ✅, Windsurf ✅, PyCharm ❌ |
| **Skills** | Cursor ✅, Windsurf partial, PyCharm ❌ |
| **Priority order** | Cursor ✅, Windsurf ✅, PyCharm manual |

## 🎓 Best Practices

1. **Single source of truth**: Always edit `.ai/rules/*.mdc`
2. **Sync frequently**: Run after every rule change
3. **Version control**: Commit both `.ai/` and generated configs
4. **Team alignment**: Share sync workflow in README
5. **IDE-agnostic**: Write rules that work everywhere
6. **Test before commit**: Run test-rules.sh
7. **Document exceptions**: If rule only works in one IDE, mark it
